SBFC static website for Cloudflare Pages

Upload the CONTENTS of this folder, not the folder itself, using Cloudflare Pages > Create application > Pages > Upload assets.

Included static public pages: Home, About, Founders, History, Pages Directory, Quran, Gallery, Contact and Donate.

Important limitations:
- Contact messages and local donation confirmations do not save to a database.
- Admin dashboard, login, finance, member management and gallery uploads are intentionally excluded because Cloudflare Pages cannot run PHP/MySQL.
- The supplied archive did not include images/logo.png, founder images, gallery photos, profiles, or visitor.php. Upload those assets separately if you have them.
